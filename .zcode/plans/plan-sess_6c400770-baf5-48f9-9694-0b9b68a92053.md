## 背景结论（调研后确认的根因）

1. **waybar 超屏**：仓库快照版 config 写死 `"width": 1600`，屏幕窄于 1720px 就溢出。你本机参考版（`~/.config/waybar/`，含 mpris/group 抽屉/updates/disk 的完整版）**不设 width**、由 style.css 的 margin 控制边距 → 天然不超屏。
2. **空白窗口 = CopyQ 主窗口**。CopyQ #3567：`--start-server` 在无托盘/晚加载 hide-main-window 配置的版本上会把主窗口显示出来（官方 FAQ：无托盘时刻意保持主窗口打开）。修复：启动参数改为 `copyq --start-server hide`（服务端后台起，客户端立即执行 hide）。另加保险窗口规则：`xwaylandvideobridge` 设 `opacity 0.0`（niri #2367 的同类白窗）。
3. **waypaper 首开壁纸失效 = 竞态**：`waypaper.service` 只依赖 graphical-session.target，与 niri spawn 的 awww-daemon 无顺序约束；waypaper 源码里 daemon 未就绪时 `awww img` 静默失败（swww #444 同款问题）。推荐方案：**自启服务 + ExecStartPre 等待循环**（轮询 pgrep+`awww query` 最多 ~15s，永远 exit 0 兜底），比改用其他方案改动最小、且随机换壁纸 timer 同样受益。
4. **bluetui**：Debian/Ubuntu 仓库都没有此包；GitHub release 提供静态 musl 二进制（`bluetui-x86_64/aarch64-linux-musl`），免组权限（org.bluez D-Bus 默认放行）。脚本已有 `_dl_gh_bounded`（直连+国内镜像）和 `github_release_asset` 可复用。
5. **fcitx5 Shift 切中英文**：参考机配置就是 `TriggerKeys 0=Shift+Shift_L` + `AltTriggerKeys 0=Shift_L`（fcitx5 允许单修饰键，`Shift+Shift_L` 与裸 Shift_L 等价），且 profile 里 DefaultIM=rime + keyboard-us/rime 组。deb 版此前整个跳过 fcitx5 目录 → 测试机上是 stock 配置（无 Shift 绑定、rime 未入组）。方案：在 `_configure_ime` 里嵌入部署 `config`+`profile` 两份参考文件；`classicui.conf`（主题美化）继续不部署，遵守上一轮“取消美化”。
6. **zsh**：deb 版有两处缺口——`load_app_universe` 把 zsh 从非 Arch 列表里过滤掉；`install_zsh_extras` 只有孤儿注释没有函数体。arch 版有完整实现（1366-1462 行）可移植。

## 实施内容（全部在 deb-install.sh 内，configs/ 快照不动）

### 1. waybar 同步参考配置 + 修超屏
- 新增 `_deploy_waybar_reference()`（挂 stage_configs，`_ensure_waybar_single_source` 之后）：
  - 嵌入你本机 `~/.config/waybar/config` + `style.css` 为 heredoc；config 仅做 Debian 适配：`custom/updates` 的 exec 改 `apt-get -s dist-upgrade | grep -c '^Inst'`（免 root）、exec-if 改 ping 223.5.5.5、on-click 改 `sudo apt update && sudo apt upgrade -y`；其余逐字保留（含 mpris/group 抽屉/bluetooth on-click `kitty -e bluetui`）。
  - 版本门控：`waybar --version >= 0.11` 才写参考版（mpris/group 抽屉需 0.10+，留余量）；旧版 waybar 保留快照版但 **sed 删掉 `"width": 1600` 行**（根治超屏）。
  - 写完仍走 `_ensure_waybar_config` 做 JSON 校验。
- `[core]` 组补 `gsimplecal`（时钟点击依赖，此前两个版本都在用却没装）。

### 2. bluetui 安装配置
- 新增 `[tools]` 包组（`bluetui ripgrep zoxide`，zsh 配置需要后两个）+ `GROUP_ORDER/GROUP_EN` 相应登记。
- `install_debian()` 特判 `bluetui → install_bluetui()`：仿 `install_nerd_font`，`github_release_asset` 按 `uname -m` 选 musl 资产，`_dl_gh_bounded` 下载到 `/usr/local/bin`，确保 `bluez` 已装并 `systemctl enable --now bluetooth.service`（失败仅警告）。
- `stage_verify` 的 PATH 检查 case 加入 bluetui（仿 niri/awww/satty）。

### 3. fcitx5 Shift 中英文
- `_configure_ime()` 内追加：幂等写入 `~/.config/fcitx5/config`（TriggerKeys=Shift+Shift_L、AltTriggerKeys=Shift_L、ModifierOnlyKeyTimeout=250 等参考机原文）和 `~/.config/fcitx5/profile`（DefaultIM=rime、keyboard-us+rime 组）。已存在时打时间戳备份再写。`classicui.conf` 仍不部署。

### 4. 空白窗口修复
- stage_configs 的 niri config 补丁段 + `repair_niri_blackscreen()`（幂等）里：sed 把 `spawn-at-startup "copyq" "--start-server"` 改为 `spawn-at-startup "copyq" "--start-server" "hide"`；config 末尾幂等追加 `xwaylandvideobridge` 的 `opacity 0.0` 窗口规则（带注释标记，重复运行不重复加）。

### 5. waypaper 首开壁纸
- 新增 `_fix_wallpaper_startup()`（stage_configs 部署后、enable 服务前调用）：给部署出的 `waypaper.service` 和 `waypaper-random.service` 幂等插入 `ExecStartPre=/bin/sh -c 'for i in $(seq 1 30); do pgrep -x awww-daemon >/dev/null 2>&1 && awww query >/dev/null 2>&1 && exit 0; sleep 0.5; done; exit 0'`（实现时先在本机确认 awww 有 `query` 子命令，没有就去掉该条件只留 pgrep）。
- `waypaper.service` + `waypaper-random.timer` 照旧启用（随机换壁纸保留，与你参考机一致）。

### 6. zsh + oh-my-zsh
- 移除 `load_app_universe` 对 zsh 的非 Arch 过滤。
- 移植 arch 的 `install_zsh_extras()`（Debian 变体）：oh-my-zsh clone（GitHub 失败用 gitee 镜像）、`zsh-autosuggestions`+`zsh-syntax-highlighting` 两个插件 clone 到 `~/.oh-my-zsh/custom/plugins/`、starship 官方脚本安装（失败则 .zshrc 的 `ZSH_THEME=""` 补成 `agnoster` 兜底）、eza（apt 没有→cargo）、bat（batcat 建软链）。前置 `pm_install git curl` 兜底。
- 嵌入一份 `.zshrc` heredoc（以你本机 85 行版为基础做净化：保留主题/插件/历史/alias 全部内容；`eza/bat/rg/zoxide/starship` 调用加 `command -v` 守卫防报错；**去掉参考机专属的 miyu hook 与 ~/.kimi-code/bin 两行**；EDITOR 按 nvim→nano→vi 探测）。zsh 被选中时：已有 .zshrc 先备份再写入；`chsh -s zsh` 设默认 shell。
