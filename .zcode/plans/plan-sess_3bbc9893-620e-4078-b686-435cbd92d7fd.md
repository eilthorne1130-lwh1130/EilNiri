## 修改项

### 1. fcitx5-qt：补 qt6-qtwayland-private-devel
根因（报告）：platforminputcontext 链接 `Qt6::WaylandClientPrivate`，该导入目标由 **qt6-qtwayland-private-devel**（Wayland 私有头文件包）提供，脚本只装了 qt6-qtwayland-devel。
修法：`SRC_DEPS_Fcitx5` += `qt6-qtwayland-private-devel`。

### 2. librime：submodule 重试（让 librime 用 vendored glog）
根因（报告）：git submodule fetch failed（网络抖动）→ librime 回退用系统 glog-devel → 系统 glog 缺 `google::IsGoogleLoggingInitialized()` → 编译中断。librime 1.16.1 的 vendored glog submodule（pin 的版本）才是 API 兼容的。
修法：librime clone 后显式重试 submodule 拉取（3 次、间隔 5s），仍失败给明确 warn（说明系统库 API 可能不兼容的后果）。

### 3. install_source_package：构建前加进度日志
消除"卡住"观感：clone 后、build_source_project 前加 `log "Building $pkg from source (log: $logf)..."` 行——源码构建全程静默输出进日志，屏幕没有这行提示就会像卡死（copyq 那次 5 分钟静默即是此因）。
