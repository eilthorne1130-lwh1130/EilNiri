# arch-install.sh 完善方案：AUR 支持 + 本机配置同步（隐私净化）

## 目标
把 WIP 的 `arch-install.sh`（2523 行）补成可用脚本：修掉现有缺口、新增 AUR(yay) 支持，并用本机（Arch 参考机）的 live 配置刷新 `configs/` 快照，让部署结果与本机桌面一致（waybar/mako/hypr/kitty/fcitx5/zsh 美化等）。CopyQ 记录等隐私数据绝不进仓库。

## 一、configs/ 快照刷新（隐私净化）

以 `~/.config` live 为准重新采集到 `configs/.config/`：

- **刷新**：`niri/config.kdl`、`waybar/{config,style.css}`、`mako/{config,focus-or-launch.py}`、`hypr/{hypridle.conf,hyprlock.conf}`、`kitty/kitty.conf`、`satty/config.toml`、`fcitx5/{config,profile,conf/*.conf}`、`waypaper/config.ini`、`systemd/user/waypaper*` 3 个单元
- **新增**：`xdg-desktop-portal/niri-portals.conf`（本机有、快照缺，缺失会选错 portal）、`starship.toml`、`gsimplecal/config`、`configs/.zshrc`（家目录点文件，stage_configs 的点文件循环已支持）
- **隐私排除（红线）**：copyq 整个目录（剪贴板历史 `copyq_tab_*.dat`、`copyq.lock`、`~/.local/share/copyq` 日志）、fcitx5 `cached_layouts` 与 rime 用户词库（`~/.local/share/fcitx5/rime`，11MB 学习数据）、`QtProject.conf`（文件对话框历史）、`mako/__pycache__`、`*.log`
- **净化**：`hyprlock.conf` 的 `/home/eilthorne` 硬编码改为 `$HOME` 占位；`waypaper/config.ini` 壁纸路径指向仓库壁纸（部署后 `_ensure_wallpaper` 也会兜底修正）；`.zshrc` 删除 `.miyu`/`.kimi-code` 私人引用；修正 `satty/config.toml` 的 root 属主
- **脚本侧隐私防线**：`stage_configs` 部署前扫描 configs/ 是否出现敏感文件名模式（`copyq_tab_*.dat`、`copyq.lock`、`*.dat`、`*.log`），命中则跳过该项并警告——防止以后误同步

## 二、arch-install.sh 代码修改

1. **新增 AUR 支持（当前最大缺口）**
   - `ensure_aur_helper`：检测 yay/paru；都没有则以目标用户 makepkg 自动安装 yay（`pacman -S base-devel git` + `git_clone_gh` 代理回退 clone + `makepkg -si --noconfirm`）
   - `install_arch` 路由拆分：每包先 `pacman -Si` 探测——官方仓库包批量 `pacman -S`；AUR 包（`awww`、`rime-ice-pinyin-git`、`polkit-gnome` 等，运行时探测为准）汇总后 `as_user yay -S --noconfirm --needed`
2. **修 bug**
   - 补定义缺失变量 `GH_MIRRORS`、`CURL_DL_FLAGS`（从 deb-install.sh 抄）；`PIP_PKGS` 置空（Arch 的 waypaper 是仓库包）
   - 移除 cargo 后台构建残留：`bg_build_start`/`stage_wait_builds` 引用的 `install_niri_from_build`/`install_awww_from_build` 根本不存在（Arch 上 niri/awww 全走包安装）；简化为无后台任务时直接标记，`status` 子命令保留
   - 删除 `stage_configs` 里"注释 `spawn-at-startup "waybar"`"的逻辑——本机 waybar 由 niri 启动且无 waybar systemd 单元，注释掉会导致部署后没有状态栏
   - `boot_env_check`/`print_niri_status` 的 gdm/AccountsService 假设改为按 DM 分支：ly 下只检查 `niri.desktop` 注册，消除 BOOT CHECK FAILED 误报
3. **系统适配**
   - `stage_preflight` 增加 locale：幂等启用 `/etc/locale.gen` 的 `en_US.UTF-8`、`zh_CN.UTF-8` 并 `locale-gen`（LANG=zh_CN.UTF-8 未生成会导致会话乱码/警告）
   - hyprlock 的 `/etc/pam.d/hyprlock` 缺失时写标准 unix auth 条目
   - polkit agent 兜底：部署后检测 niri config 里 agent 路径，二进制不存在则按已装 agent 改写（参考 deb 的 `resolve_polkit_agent`）
4. **包清单增补**（waybar 配置实际依赖）：`pacman-contrib`（checkupdates 模块）、`zenity`（关机/重启确认框）、`gsimplecal`、`ripgrep`、`zoxide`、`bluetui`（新 tools 组）；`brightnessctl` 已在 media 组（niri 亮度键依赖）；不装 noto-fonts-cjk（与本机一致，wqy-zenhei 兜底）
5. **zsh 美化**（`install_zsh_extras` 调整）
   - starship 安装优先级：pacman 包 → yay → 官方 curl 脚本兜底（实现时用 `pacman -Si` 探测决定）
   - 部署 `starship.toml` + `.zshrc`；oh-my-zsh 与 autosuggestions/syntax-highlighting 两插件 clone 逻辑保留
   - `ZSH_THEME=""`→`agnoster` 的兜底改为仅在 starship 未装成功时生效
   - 新增 zoxide 安装（.zshrc 已有守卫）
6. **DM 维持 ly**（已确认）：stage_dm 不动；`ensure_dm_session` arch 分支保持 no-op
7. **不做 update 子命令**（已确认）
8. **收尾**：`SCRIPT_VERSION` bump、README 的 arch WIP 标注更新为可用、usage 帮助同步
