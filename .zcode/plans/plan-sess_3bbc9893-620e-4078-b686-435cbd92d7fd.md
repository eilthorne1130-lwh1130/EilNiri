## 诊断（来自你的日志）

好消息：链已推进到最后阶段——日志显示 waybar、hyprlock、hypridle、copyq、satty、grim 全部构建成功（**copyq 的三条降级开关完美生效**：qca/qtkeychain/ECM 装上、miniaudio 缺 → WITH_AUDIO=OFF、无 KF6 → WITH_NATIVE_NOTIFICATIONS=OFF），fcitx5 core 的 cmake 也走过了 XKBCommon(X11)、xcb-imdkit、Wayland 等所有前序关卡，**只卡在 CMakeLists.txt:124 的 json-c**。

|---|---|
| `json-c-devel` | 本次失败点（CRB 有） |
| `fmt-devel` | `find_package(fmt REQUIRED)`（CRB/EPEL 有） |
| `libuv-devel` | systemd cmake target 缺席时的 event loop 后备（AppStream 有） |

同时确认 `nlohmann-json-devel` 是 5.1.23 的依赖、5.1.10 完全不用——从清单删除。
