## 修改项

### 1. fcitx5-qt 根治
- `CMAKE_EXTRA_ARGS=(-DBUILD_ONLY_PLUGIN=ON -DENABLE_QT5=OFF -DENABLE_QT6=ON)`——已查证 qt6/CMakeLists 的 `if(NOT BUILD_ONLY_PLUGIN)` 包住 guiwrapper/widgetsaddons/quickphrase-editor/immodule-probing（出错的组件全部在内），只剩 dbusaddons + platforminputcontext（输入法模块本体）；顶层还跳过 Fcitx5Utils 依赖——对 core 版本的依赖面归零
- `SRC_DEPS_Fcitx5` += `qt6-qtbase-devel qt6-qtbase-private-devel qt6-qtwayland-devel`
- 代价：不装 fcitx5-qt 的 Qt 配置 GUI——配置已随脚本部署，无损失

### 2. rime 链外部库源码兜底（新增 install_rime_build_libs()，条件触发装 /usr）
- **leveldb**（实测缺）：`google/leveldb` + cmake `-DLEVELDB_BUILD_TESTS=OFF -DLEVELDB_BUILD_BENCHMARKS=OFF`（crc32c submodule 由 git_clone_gh 自动拉）
- **opencc**：`BYVoid/OpenCC` + cmake（纯 C++）
- **marisa**：`s-yata/marisa-trie` + autotools（`autoreconf -i` → configure → make install；依赖清单补 `autoconf automake libtool`）
- 检测方式：pkg-config 不可得才触发，已装跳过；各自失败 → MANUAL 不中断后续
- `install_fcitx5_rime_source` 清单 += `glog-devel autoconf automake libtool`；librime 构建命令 += `-DBUILD_TEST=OFF`
- 顺序：外部库兜底 → librime 1.16.1 → fcitx5-rime 5.1.10 → rime-ice 词典自动部署
