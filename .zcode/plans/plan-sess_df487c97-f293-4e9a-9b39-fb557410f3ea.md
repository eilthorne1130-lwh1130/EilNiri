# laptop-need-install.sh 编写计划（修订版：与三个主脚本搭配使用）

## 定位
- 补装脚本：用户运行 arch-install.sh / deb-install.sh / RHEL-install.sh 完成 eilNiri 安装后，在**笔记本**上运行，给已部署好的 waybar 添加电量模块。头部注释明确写明这一搭配关系。
- **骨架、输出风格、调用习惯对齐三个主脚本**，但不修改三个主脚本；唯一改动文件仍是 `laptop-need-install.sh`。

## 结构（对齐 deb-install.sh 骨架，约 260 行）
1. **头部**：shebang + `SCRIPT_VERSION` + 免责声明 echo + Usage（`sudo ./laptop-need-install.sh [--dry-run]`；也允许普通用户直接运行）。
2. **基础**：`set -uo pipefail`；`cleanup` trap（清理临时文件 + 中断提示，同 deb:40-58 简化版）；`_t() { echo "$2"; }`（与主脚本完全同款的占位实现，当前输出英文）；配色变量、`log/success/warn/error/info_kv`、`confirm`（read -t 超时，同 deb:178）；`write_log` 写入 `$LOG_DIR/laptop-need.log`（LOG_DIR 解析与 sudo 下 `~/.local` 属主修复同 deb:85-102）。
3. **身份解析（双模式，覆盖搭配与单跑两种用法）**：
   - root/sudo：与主脚本一致——SUDO_USER 优先，否则 uid 1000，再否则首个普通用户；定位 HOME_DIR（deb `detect_target_user` 的简化无交互版）；
   - 非 root：TARGET_USER=当前用户、HOME_DIR=$HOME。
4. **前置检查**：`$HOME_DIR/.config/waybar/config` 存在（否则提示先运行主安装脚本后退出）；python3 存在。
5. **电池探测**：`/sys/class/power_supply/*/type` == "Battery"（同 deb:3228-3235），结果作为 confirm 默认值（15s 超时；选 N 直接退出）。
6. **备份**：`config` / `style.css` → `.bak-bat-$TS`。
7. **JSON 注入**（python3 heredoc，**原子写** `.tmp → os.replace`，tmp 注册进 cleanup）：`"battery"` 插入 `modules-right` 中 `"tray"` 前（幂等，无 tray 放最前）；模块定义与 deb `_waybar_add_battery` 完全一致（format/format-charging/format-plugged/format-icons/states warning 30 critical 15/中文 tooltip），**仅 `interval: 10`**；解析失败 → warn 中止，原文件未动。
8. **CSS 追加**（幂等 `grep -q '^#battery {'`）：deb 同款"第 13 节 Battery"样式块——基础 pill + 绿色左竖条 `rgba(166,227,161,0.55)` + hover；状态色规则 style.css 已有，不重复加；style.css 缺失则警告跳过。
9. **chown**：root 模式下写完后把两个文件归还目标用户（同 deb:3309-3310）。
10. **自动重启 waybar**：
    - `pgrep -x waybar` 且有图形会话时：root 模式从 `/proc/<pid>/environ` 提取 `WAYLAND_DISPLAY/XDG_RUNTIME_DIR/DISPLAY/DBUS_SESSION_BUS_ADDRESS`，pkill 后 `runuser` 以目标用户 `setsid` 拉起（存在 `/usr/local/bin/eilniri-waybar-start` 守卫则走守卫，保持单实例来源一致）；环境提取失败则**不 kill**、只打印手动提示；
    - 非 root 模式：直接 pkill + `setsid waybar &`；
    - waybar 未运行或无图形会话 → 打印手动提示；`--dry-run` 只打印将执行的命令。
11. **收尾**：success + 备份路径 + 回滚方法（`cp xxx.bak-bat-$TS` 覆盖回去）。

## 幂等与边界
- 重复运行安全；若 deb 安装时已加过 battery（interval 30），重跑本脚本会刷新为 10。
- 台式机误跑：探测不到电池时 confirm 默认 N，选 N 无任何改动。
- config JSON 非法 → 中止不动文件。

## 验证（本机是参考机，不实际执行脚本、不碰真实配置）
- `bash -n` 语法检查（shellcheck 若可用也跑）；
- python3 注入片段以**内存方式**（stdout，不落盘）对 `configs/.config/waybar/config` 验证：battery 位于 tray 前、interval=10、JSON 合法、其余模块无损；
- 绝不触发 restart_waybar 等真实动作。
