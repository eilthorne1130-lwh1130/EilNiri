🧪 推荐测试步骤
═════════════════════════════════════════════════════════════════════════════

在 Debian 12 / Ubuntu 24.04 系统上按顺序执行：

第一步：基础检查
  □ bash -n install.sh                    # 语法检查（应无输出）
  □ ./install.sh --help                   # 帮助信息
  □ ./install.sh collect-config           # 采集配置（普通用户）

第二步：干运行（推荐先做这个）
  □ sudo ./install.sh restore --dry-run   # 显示计划，不做改动
  # 查看是否正确识别 Debian 包名和系统组件

第三步：完整安装测试（可选，需要 2-3 小时）
  □ sudo ./install.sh restore             # 执行完整安装
  □ ./install.sh status                   # 监控后台编译进度
  # 验证 niri 编译成功
  # 验证系统组件正确禁用

第四步：验证禁用结果
  □ systemctl --user list-unit-files | grep masked
  □ systemctl list-unit-files | grep masked
  □ ls ~/.config/autostart/ | grep Hidden
  # 确认禁用项目真的被掩码或隐藏


⚡ 快速故障排查
═════════════════════════════════════════════════════════════════════════════

问题 1: niri 编译仍然失败
  👉 查看日志：tail -100 ~/.local/state/eilNiri/niri-build.log
  👉 检查依赖：dpkg -l | grep -E "build-essential|clang|libwayland"
  👉 安装缺失：sudo apt-get install build-essential clang libwayland-dev

问题 2: 系统组件未被禁用
  👉 查看禁用清单：cat .system_disabled
  👉 检查掩码状态：systemctl --user list-unit-files | grep masked
  👉 强制重做：rm .replicate_progress && sudo ./install.sh restore

问题 3: 下载失败反复重试
  👉 使用镜像：EILNIRI_GH_PROXY="https://ghfast.top/" sudo ./install.sh restore
  👉 查看错误：grep "download\|clone" ~/.local/state/eilNiri/replicate.log
